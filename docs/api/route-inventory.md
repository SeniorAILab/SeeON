# Route Inventory

Current route inventory for issue #216 plus the post-rename facility/placement routes. Auth names match backend guards: `SessionGuard` requires a valid session cookie and `RequireFacilityGuard` requires `user.facilityId`. Product `/api/v1/*` JSON responses use camelCase for frontend consumption; the ML Event API is no-HMAC and resolves facility ownership from `camera_id`.

## Event API contract

`POST /api/v1/events` and `POST /api/v1/events/heartbeat` are the only live ML ingress endpoints. They are no-HMAC, accept JSON bodies with `camera_id`, and resolve facility/space ownership from the backend camera record. Legacy machine-ingest routes, camera HMAC credentials, and `Camera.ingestMode` are removed and must not be retained as compatibility aliases.
